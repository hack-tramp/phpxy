**EZTV** - this will let you search for and download torrents using the EZTV api. Currently you can only download magnet links.

**TPB (The Pirate Bay)** - thepiratebay.org this will let you search for and download torrents using the pirate bay api. Currently you can only download magnet links. It also shows the top and recent torrents in each category: audio, video, apps etc.

**How to use** 

For these scripts to work you will need to place them on a server in a country which does not restrict access to the site you want (e.g. EZTV).
